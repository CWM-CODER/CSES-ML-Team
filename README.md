# CSES ML Team — Progress Tracker

This repository is the **learning and progress tracker for the CSES ML Team**.

Every 2nd-year member must maintain their own folder and **update their work every week**. This repository helps mentors track the learning progress, implementations, and projects of their mentees.

> **This is not just a code repository. It is a record of your learning journey.**

## Repository Structure

Each member must create **one folder using their full name**.

```text id="f4w0m0"
CSES-ML-Team/
│
├── README.md
│
├── Member_Name_1/
├── Member_Name_2/
├── Member_Name_3/
└── ...
```

### Example

If your name is **XYZ**, create:

```text id="bj9m6c"
XYZ/
```

Your folder should follow this structure:

```text id="gk5oy4"
XYZ/
│
├── README.md
├── Week_01/
├── Week_02/
├── Week_03/
└── Projects/
```

## Weekly Updates

**Every member must update their folder every week.**

Create a new folder for each week:

```text id="1d4flk"
Week_01/
Week_02/
Week_03/
Week_04/
...
```

Upload the work completed during that week inside the corresponding folder.

For example:

```text id="6c7o9j"
Week_03/
│
├── Logistic_Regression.ipynb
├── notes.pdf
└── results.png
```

## Projects

Every major project should have its **own folder** inside `Projects/`.

Example:

```text id="gk5f7v"
Projects/
└── Movie_Sentiment_Analysis/
    ├── code/
    └── results/
```

Keep all relevant project files organized inside the project folder.

## Guidelines

* Keep your code and projects clean, organized, and properly structured.
* Use meaningful file, variable, function, and commit names.
* Update your folder **every week**.
* Keep weekly work inside the corresponding `Week_XX` folder.
* Document your work where necessary.
* Try to **avoid simply copy-pasting code** from external sources. Understand the code and make an effort to implement it yourself.
* Do not upload unnecessary files such as `.venv`, `__pycache__`, `.env`, etc.
* Keep sensitive information such as API keys and passwords out of the repository.

## The Goal

Your folder should show your journey:

**Learn → Implement → Build → Document → Improve**

By the end of the mentorship, your GitHub folder should clearly demonstrate **how you have progressed as an ML learner.**

**Be consistent. Keep learning. Keep building. 🚀**
